# Сайт для родительского собрания

Файлы:
- `index.html` — интерактивная презентация (показывается родителям, весь текст на казахском)
- `teacher.html` — страница для просмотра всех сохранённых ответов (только для тебя)
- `firebase-config.js` — настройки базы данных (нужно заполнить своими ключами)

Ответы сохраняются в **Firebase Firestore** — бесплатная база данных от Google, без своего сервера.

---

## Шаг 1. Создать проект Firebase (5 минут)

1. Зайди на https://console.firebase.google.com (через Google-аккаунт).
2. **Add project** → введи название (например `ata-analar-zhinalysy`) → **Continue** → Google Analytics можно отключить → **Create project**.
3. В открывшемся проекте, в левом меню: **Build → Firestore Database**.
4. **Create database** → выбери **Start in test mode** → выбери ближайший регион сервера → **Enable**.
   - Test mode держит базу открытой 30 дней — для собрания этого достаточно. Как закрыть потом — см. в конце файла.

## Шаг 2. Подключить веб-приложение и получить ключи

1. На главной странице проекта (Project Overview) нажми значок **`</>`** (Web).
2. Введи название приложения (например `ata-site`) → **Register app**.
3. Появится блок кода вида `firebaseConfig = { apiKey: "...", ... }` — скопируй его целиком.
4. Открой файл **`firebase-config.js`** в этом проекте и замени значения в `firebaseConfig` на свои, скопированные.

Пример, как это должно выглядеть:
```js
export const firebaseConfig = {
  apiKey: "AIzaSyD...",
  authDomain: "ata-analar-zhinalysy.firebaseapp.com",
  projectId: "ata-analar-zhinalysy",
  storageBucket: "ata-analar-zhinalysy.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
```

Сохрани файл — теперь `index.html` и `teacher.html` подключены к твоей базе.

## Шаг 3. Проверка

Открой `index.html` в браузере (обычный двойной клик по файлу). Заполни что-нибудь на любом слайде (например, добавь "яблоко" на дерево) — внизу экрана на секунду должно появиться **«✓ Сақталды»**.

Затем открой `teacher.html` и нажми кнопку **«Жаңарту»** — новая запись должна появиться в списке.

## Шаг 4. Залить проект на GitHub (через VS Code)

1. Открой эту папку в VS Code.
2. В верхнем меню: **Terminal → New Terminal**, и по очереди введи:

```bash
git init
git add .
git commit -m "Сайт для родительского собрания"
```

3. На сайте GitHub (https://github.com/new) создай новый пустой репозиторий (например `ata-analar-zhinalysy`), галочку «Add a README» не ставь.
4. Скопируй команды, которые покажет GitHub, и выполни их в терминале (примерно так):

```bash
git remote add origin https://github.com/ТВОЙ_НИК/ata-analar-zhinalysy.git
git branch -M main
git push -u origin main
```

(То же самое можно сделать без терминала — через панель **Source Control** в VS Code слева: кнопки «Commit» и «Publish Branch».)

## Шаг 5. Опубликовать сайт (GitHub Pages, бесплатно)

1. В репозитории на GitHub: **Settings → Pages**.
2. **Source** → **Deploy from a branch** → Branch: `main`, папка: `/ (root)` → **Save**.
3. Через минуту-две появится ссылка вида:
   `https://ТВОЙ_НИК.github.io/ata-analar-zhinalysy/`
4. Это и есть презентация. Страница с ответами: `.../teacher.html`

## Важные моменты

- **Приватность:** в test mode базу может читать/писать любой, у кого есть ссылка на проект (не сама презентация, а прямой доступ к базе). Для разового собрания это нормально, но после него стоит зайти в Firebase Console → Firestore → **Rules** и закрыть запись, либо вообще удалить проект.
- Имя и фамилия родителя нигде не спрашиваются — только необязательное поле «Имя ребёнка».
- Если `firebase-config.js` не заполнен — сайт всё равно работает (слайды, интерактив), просто ответы не сохраняются, и на экране будет предупреждение «⚠ Сақталмады».
